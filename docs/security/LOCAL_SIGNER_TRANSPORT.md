# 独立密钥服务的本地连接协议

2026-09-15。已实现客户端适配器并通过固定测试密钥联调；尚未配置真实密钥服务。

## 进程与权限

行情、web 与策略进程不持有私钥。可信策略检查服务运行 `LpSignerSidecar`，只有其
静态策略、nonce 预约等检查通过后，才调用 `SocketKeyProvider`。密钥服务由操作者
另外部署，签名后返回标量；sidecar 重建完整 EIP-1559 交易并恢复签名地址。

适配器只连接本机 AF_UNIX socket。路径必须为绝对路径且不超过 100 个文件系统字节；
拒绝符号链接。父目录必须归当前用户所有且权限为 0700，socket 为同用户所有且权限
为 0600。连接前后核对 inode/device。真实部署应让策略进程使用另一个无权访问 socket
和私钥文件的 OS 身份。两个同用户进程之间没有因“分进程”自动获得安全隔离。

这不是密钥服务端实现，也不是对服务端的远程证明。目录权限不能限制同用户恶意程序，
服务端仍是受信任密钥权威；只接收摘要的接口不能独立判断交易经济含义。

## 请求与响应

每条连接只发送一条 canonical JSON 加换行：

```text
request: {schema: "oasis.digest-signing.v1", account: canonical_address,
          digest: 0x + 64 lowercase hex}
response: request 的全部字段，加 r、s、y_parity
```

响应同样必须为 canonical JSON，以一个换行结束；账户、schema 和 digest 必须完全
匹配请求，不能多字段或重复字段。r/s 为各 32 字节的小写十六进制字符串，要求有效
secp256k1 范围及 low-s；y_parity 为整数 0 或 1，布尔值不合法。

响应最多 2048 字节。总 I/O 预算默认 3000ms，显式允许 1..10000ms；连接、写入和
分块读取共用期限，不能通过不断发送少量字节延长等待。超时、截断、无效签名或
文件权限错误均拒绝，不自动重试，也不输出后端异常详情。

签名结果的默认 repr 隐藏原始交易字节，但授权调用方仍能读取该字段；不得把完整对象
序列化到日志或报告。

sidecar 将一次失败的外部签名尝试保持为未解决 nonce，阻断后续签名。超时不能证明
服务端没有签名，因此不能换 nonce 继续。当前生产级解除未决状态流程仍待完成。

## 接入方式与当前边界

受信任的 sidecar 启动器可显式创建 `SocketKeyProvider(path, policy.account)`，作为
`LpSidecarConfig.provider` 传入。默认无 provider 的 CLI 行为保持拒绝；本轮没有把
socket 暴露给 web/策略，也没有加载 `.env` 私钥或新建通用摘要签名服务。

本地私钥可以由将来的独立密钥服务加载专属密钥文件，正常交易不需要逐笔人工确认。
目前仍缺专用交易钱包用途、资本/亏损限额、密钥服务部署、独立发布证据验证以及签名
后的广播状态/核账闭环。适配器通过测试不等于获准实盘；它也不会授予新的 release 权限。
