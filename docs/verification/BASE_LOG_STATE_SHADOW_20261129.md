# Base 日志推进池状态与直接子头前发现

北京时间 2026-11-29。此前 Base 每个头都要重新远程读取池状态，58 池完整状态需要 1.8–3.2 秒，而直接子头约 200 ms 后到达，各轮及时率为 0/N。本轮改为一次按块哈希固定的种子读取，之后只靠 WebSocket `logs` 推进状态。**稳态 294 个块中，292 个块的首次本地扫描在直接子头之前完成**，首扫 p50 为 34.8 ms。官方节点按同一块哈希做了 18 次独立全量对账，价格、tick、活跃流动性、储备以及 47 个 CL 池窗口内的 tick 净流动性均为零差异。自然正候选为零，所以这一轮只改进时效和覆盖，不涉及盈利结论。全部为只读影子，RPC 支出 USD 0，没有签名或广播。[此前同头取数](BASE_INCREMENTAL_STATE_AB_20261127.md) · [状态模块](../../src/oasis_agent/fastpath/base_log_state.py) · [采集与复核程序](fixtures/run_base_log_state_shadow.py)

## 方法

V3／Slipstream 的 `Swap` 事件带有成交后的 `sqrtPriceX96`、`tick` 和活跃 `liquidity`；Aerodrome V2 的 `Sync` 带有成交后的储备。因此同一池在一个块里的最后一条日志就是该池的块末状态。漏掉一条日志只会让该池停留在旧状态，直到下一条日志出现，误差不会累积。`Mint`／`Burn` 带有 `tickLower`、`tickUpper` 和数量，可以直接改写窗口内的 tick 净流动性。

- **种子。** 收到第一个头后，在同一块哈希上读三次：池价格、流动性、费率和 tick spacing；每个 CL 池当前 bitmap 字及两侧各一字；活跃 tick 两侧各最近 16 个已初始化 tick 的 `ticks()`。第 17 个 tick 作为排空边界，不计其净值。Uniswap V3 `ticks()` 返回 8 个字，Slipstream／Aero CL2 返回 10 个字，按池类型严格校验长度。
- **订阅。** 只按 5 个 topic 过滤（CL Swap／Mint／Burn、V2 Sync112、Aero Sync256），不按地址过滤。PublicNode 匿名 `eth_getLogs` 最多接受 10 个地址，WebSocket 订阅按地址和按 topic 都能用。未跟踪的池只计入成交统计，不进入状态。
- **完整性。** 块头的 `logsBloom` 只作提示：Bloom 命中的跟踪池都已有日志，或者 80 ms 超时，即开始首扫；之后每来一条日志就重扫。块 N 在头 N+2 到达时才确认。之前的一次 60 头窗口里，块 63,510,418 的两条跟踪池日志比头 N+1 晚到 22.3／25.6 ms，按当时“收到子头即确认”的规则停机，原件已保留。确认时，有日志但不在 Bloom 中，或者块已确认后仍收到它的日志，都会停止并要求重新种子。
- **动态费。** Slipstream／Aero CL2 的费率会在不发日志的情况下变化。冒烟窗口中 `aero_cl2_weth_usdc_ts100` 在三次固定读取之间是 638→886→638 pips。正式窗口每 4 块用一次 Multicall 读取所有 CL 池的 `fee()`，不在关键路径上，扫描时叠加最近一次读数。300 头窗口中有 30 次费率变化，扫描所用费率最长滞后 6 块。
- **扫描。** Rust 驻留图逐块推进，每块只传有变动的池。WETH 与 USDC 两个锚点、最多 3 跳，成本与此前 58 池扫描相同：550,000 L2 gas ×（base fee + 1,000,000 wei）加上 600 字节的 L1 费用上界。

深度窗口的直接子头间隔 p50 为 200.2 ms。驻留图扫描 p50 为 28.9 ms、p99 为 43.2 ms，每块评估 3,370 条环路。跟踪池共 622 条日志，按类型为 Swap 151、Mint 106、Burn 316、Sync 49。块 N 的最后一条跟踪日志在本块头之后 p50 12.7 ms、最长 103.1 ms 到达，本窗口没有晚于子头的情况。迟到日志共触发 143 次重扫。有 21 个块存在 Bloom 命中但无跟踪日志的池，多为不改价格的事件或 Bloom 碰撞，由对账兜底。

两个窗口中自然正候选均为零。每次首扫还剩 74–84 个未闭合定量区间。读 Rust 源码可知，`size_indexed_cycle` 只在最后一跳为 V2 时计算输出上限；以 CL 结尾的路线上界取 `U256::MAX`，记录值接近 2^256。这些区间只说明**没有计算上界**，不代表其中有机会。

为此新增了精确有理数的现价上界：CL 和 V2 的精确输入兑换满足 `out ≤ in ×（1 − fee）× 现价`，逐跳相乘得到 `R`，区间 `[lo, hi]` 的净额不超过 `hi ×（R − 1）− 成本`。单元测试在两种池型、两个方向和四档金额上验证了原生报价不超过这个界。[上界模块](../../src/oasis_agent/fastpath/cycle_bounds.py)

另跑一个 120 头窗口（63,513,9xx–63,514,1xx，ledger 56 次），3,744 个未闭合区间中可证伪的为 **0**。原因是 Rust 只对“逐跳扣费后现价乘积 > 1”的环路做定量，留下的区间全都是扣费后现价确有正差的环路，现价上界无法排除它们。113 个稳态首扫中，最优未闭合区间每次都含 `slipstream_weth_usdc_ts1_f8f2eb`，上界 p50 为 810,835,021,747,088 wei。用审计原件离线复算块 63,513,993：该池与其余五个 WETH/USDC 池的扣费后现价相差 2.6–8.1 bp。毛差在 0.00001 WETH 时为 +5,905,476,942 wei，0.0001 WETH 时已降到 −81,595,117,929 wei，0.001 WETH 时为 −12,608,386,776,392 wei，更大金额超出窗口。这是一个持续存在但几乎没有深度的价差，远不够覆盖整笔 gas。

300 块里只按 topic 订阅看到 170 个未跟踪的 CL／V2 发射地址有成交，可作为扩池候选的分母。其中有多少能通过工厂身份、代币和流动性核验，尚未测量。
