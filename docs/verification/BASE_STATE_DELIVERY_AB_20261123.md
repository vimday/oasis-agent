## 样本和门槛

两臂顺序交替。每臂都在前一阶段后等待 300 ms，保持同一来源最多一个在途请求。
原始账本每来源最少间隔 250 ms，累计 27 次匿名免费请求，PublicNode 14 次、Base 官方
13 次。两次链 ID、八次头部、一次固定块 PoolManager 运行码和十六次 Multicall 均成功，
费用为 USD 0。任一传输、哈希或完整性失败均阻断当组发布，已经发出的请求继续记账。
[PublicNode Base](https://base.publicnode.com/) ·
[Base 官方免费公共 RPC](https://docs.base.org/get-started/connect-to-base)

每臂只有两份结果均收到并通过解码后才合并。八次完整输出均含 58 个地址池、
8 个完整 PoolId、固定块 V4 bitmap 边界、L1 探针、L2 base fee 与 operator 参数。
四对合并快照的规范 JSON 字节和 SHA-256 逐对完全一致。双端核对的是块身份，
每个池子集的状态由对应单一来源提供。
