- ERC-20 宽规则要求同币、同持有人账本中相邻的两笔实际收付，按原始整数完全等额。同样分别计日志形态、已验证市场边界、两个已验证独立闭环。普通资金流解析另给严格市场腿之间的资金边数，可包含同一笔转账直接到下一池。其覆盖与同持有人两次转账的覆盖交叉。
- 另比较同币同持有人按资金端点相邻、互不重叠且边界无歧义的闭环对。验证前轮末额是否等于次轮本金。前轮本金等于次轮本金、同时前轮末额不同，可作为固定额重复的代理。上轮和次轮金额一致本身也无法排除可替代库存，条件包括可见账本的覆盖。
