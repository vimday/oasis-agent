## 固定本金和复投的离线搜索

**假设。** 同一固定本金可以多次使用。若每轮收到的差额递减，最佳停止轮数取决于共享固定费、逐轮成本和池储备变化。用持有作为零轮基线。比较每种固定本金的所有可行前缀和同状态、同初始资产的异路线组合。输入包含池、方向、锚定资产、实际使用的整数与费用情景。本轮将新增方式接入 `scripts.replay_v2_batch_comparison` 的 v2 搜索计划，已有 v1 的输出保持可重建。[CLI](../../scripts/replay_v2_batch_comparison.py) · [整数内核](../../src/oasis_agent/fastpath/v2_batch.py)

- 每份本金从首轮开始冻结。先预留一次整笔固定成本，每一轮在上一轮更新后的整数储备上报价，利润留存在余额内。后续本金保持原数；每一轮都重新检查可支付成本及余额。程序输出每个前缀的到账、相对上一可行前缀的边际净额、累计净额和最短最优轮数。首轮边际已经扣共享固定成本。
- 每条路线最多 200 轮、每个前缀最多 512 条池腿。达到申报的成本门槛、资金、整数范围或输出条件时决定本轮是否可继续。被拒的下一轮不会扣掉已选择的较短前缀收益。实际失败提交的机会成本与费用，仍须在策略层单列。
- 相同路线若有 N 个可行前缀，只需按顺序扩展 N 次。用独立的整条重放逐前缀核对金额；例如 200 个两跳前缀，增量方法只需处理 400 条成功池腿，从初始快照重算每个前缀需 40,200 条。这个数是算法工作量；生产耗时还含取数、状态和整笔验证。
- 这一模型覆盖标准到账的恒定乘积池。历史 OP 与 Arbitrum 批次的逐轮收入来自收据。实际合约能否提前结束、每删一轮可真正省多少 gas，必须用对应链的执行语义核验。OP 的 L1 费、Arbitrum 的 L1 发布分项均按该笔交易所处时代的付费规则处理。[95 轮收入与阈值](REPEATED_CYCLE_MARGINALS_20261127.md) · [Optimism 费用](https://docs.optimism.io/op-stack/transactions/fees) · [Arbitrum 费用](https://docs.arbitrum.io/how-arbitrum-works/deep-dives/gas-and-fees)

## 复投途中能否换池

V2 离线 v4 入口可以在全额复投时切换路线。它先按首轮本金分组，在各组当前储备状态下，用同一笔全额回款试算所有仍容得下的候选，以费用后余额和固定路线 ID 顺序选出下一轮。只将中选路线的储备与现金变化带入后续轮次。任何完整前缀都可以提前结算，持有是零轮方案。总逐腿预算无法覆盖整轮时，保留上一次完整选择。每条轨迹最多 200 轮、512 条池腿。交付物是贪心轨迹上的最佳前缀，其他可能更优的路线序列仍待检验。[实现与逐轮复放测试](../../tests/unit/test_v2_batch.py)
