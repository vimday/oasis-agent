# 实时 Swap 到定向报价预注册

2026-11-14，基线 `efa0b93`，Codex。前次 Base/Elysium 样本只用于选池和定时。
本次是新的前瞻可行性窗口，每链一次，启动前固化下列规则。资本、签名和广播均为零。

- Base 8453 观察 Uniswap V3 WETH/USDC 500 池 `0xd0b53d9277642d899df5c87a3966a349a798f224` 的 Swap。
  路线是 0.01 ETH → USDC（V4 原生 ETH/USDC、500、spacing 10、零 hook）→ WETH（被观察的 V3 池）。
  ETH/WETH 以链内 1:1 计价，解包成本纳入 gas 假设。只测这个腿序与规模。
- Elysium 99901 观察 `0xe2e105d3f7209a9da11f83ccf3e7398a753823f1` 上原 HYPE/KNTQ
  V4 PoolId `0xf9b8a9101438145d62c9f03156b203c6c573931167e2d36f9061a32575706c8a`
  的 Swap。原计划路线 0.01 HYPE → KNTQ → USDC → WHYPE 暂无已核验的 V4 PoolKey 和 V3/V4
  Quoter，预先降级为事件和收据覆盖，两个报价组均禁用。这一链没有报价成功率或收益分母。
- 链内时间窗为两订阅确认后 90 秒。Base 事件组按本机单调时钟，从首个不同块的 Swap 起立即
  发起固定哈希报价，最多 4 次。基线组在 +5、+30、+55、+80 秒分别读最新块并以返回哈希
  完成相同报价。每组每次最多 4 个读取（块头、两腿、L1 发布费上界），总上限 16/组。
  订阅、启动身份校验和结束后复核独立计账。轮询只在首次接收后 750 ms 内开始、且区块不早于
  触发块时计为同一机会的对照，另外报告更晚的首个可比较样本和各组独立完成率。
- 时限为 750 ms，事件组从 WS 原始帧交付到第二腿响应解码完成，轮询组从计划时刻到第二腿
  响应解码完成。启动偏差、L1 费返回时刻和实验后对账另记。块末哈希 EIP-1898 强制 canonical。
  机会定义为 750 ms 内完成报价及可复核的负/正净差。固定算例在池费和冲击已包含后，再扣
  500,000 gas ×（同块 base fee + 0.001 gwei tip）和 Base Oracle 的 600 字节 L1 fee 上界。
  假设 600 字节包络、500,000 gas、无借贷或私有 builder 出价，只有观测模型，没有实际交易账。
  两个 Quoter 的单池 gas 仅是诊断，实际包络、gas、排序、运营者费、失败和机会成本都未验证。
  毛差 ≤0 确定没有正净差。其余样本的模型净差独立保留，实际净差为未知。
- 先收的同块后续日志只增加覆盖。按块高检查冲突和相邻父哈希，removed 立即失效。收尾用
  `eth_getLogs` 补到结束水位，优先按有界块段查询。发现漏收、断线或重组不补记实时接收时间。
  使用另一运营商核对选中事件的块哈希、收据状态、交易位置以及日志字节，并复查候选块和窗口
  首尾；两头可能有订阅/查询竞态，竞态区独立计数。退出后断线按原捕获上下文对账，运营商拒绝
  或 HTTP 429 后停止该范围并留痕。本地证据不依赖交易凭据。
- 关停这条固定 Base 路线需累计 4 个无缺口、独立复核完成的不同 Swap 块，且无一在时限内
  完成并给出正的模型净差。净差无法判定、样本不足、供应商拒绝和重组都判为不完整。
  正模型净差仅保留进一步验证线索。该门槛仅用于本试验，正式经济评估另需 untouched 队列、实际
  成本、净 NAV、基准和尾损。
