## 冻结设计

费用筛选按 310,551 gas、该头的 base fee、冻结优先费、L1 及 operator 费用上界。正门槛是 1 wei。若发现正例，固定本金、池序、模拟运行码与交易包络，由 Base 官方和 dRPC 分别核整笔。K 以双源结果复核结束时本机已见最新头为准，C 以父哈希严格验证的直接子块为准。两处同本金复算用各自哈希的费用上下文。[此前等额报价基线](BASE_BATCHED_NATURAL_20261128.md) · [实际本金的有界报价](BASE_CL_COVERAGE_20261128.md)
