# Base 同哈希双头重叠与连续影子覆盖

常规混合影子增加 `--base-newheads-overlap-headers`。由已留存的新头同时启动两个来源的
固定高度请求。每条来源路径先验证自己返回的头，再按哈希读取对应状态，两份完整块头一致后
才提交组合快照。跨块仍按序处理。两臂每块都预留两次 PublicNode 和三次 Base 官方请求，
命中首个失败即停。状态清单新增双头实际传输重叠时钟，保留旧清单回放。

## 同两个直接父子块的两臂交叉

北京时间 09:58:10.952 的 **61,475,576 → 61,475,577** 共两次采样。每个块分别按旧顺序
和新顺序各取一次，首块旧臂先运行，次块新臂先运行。两臂用同一组 RPC 客户端、来源、原始
账本、池名单和金额。每对五份请求字节和解码后的状态字节完全相同。实际用完 **23/23**
个免费预留，包含 3 个 WebSocket 连接和控制预留、8 次 PublicNode 和 12 次 Base 官方 HTTPS。

| 块 | 到状态就绪，旧臂 / 重叠臂 ms | 两头传输重叠 ms | 节省 ms |
| ---: | ---: | ---: | ---: |
| 61,475,576 | 1,559.510 / 844.320 | 121.510 | 715.190 |
| 61,475,577 | 988.621 / 859.048 | 134.932 | 129.573 |

表内时钟从各臂开始状态采集算起。首块旧臂承担冷连接，第二块仍测得 129.573 ms 差值。
交叉实验中的另一臂和后继块等待前一轮完成，原始收帧到状态的四个用时依次为
1,563.011、2,409.097、3,150.488、4,142.480 ms。四份快照均超过 750 ms。
每个块的 4、58、66 池全部通过 Rust 双图对照，固定 L1/L2 模型正候选与整笔模拟均为零。
