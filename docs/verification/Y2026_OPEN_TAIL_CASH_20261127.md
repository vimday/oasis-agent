## 同一类借款，三种结算结果

**Optimism，四池闭环加第五池变现。** 在预选的带融资事件收据中另设独立的付款核算，重建该块 37 份收据的树根，核对目标全部日志及 2,944 帧调用。贷款方给回调持有人 596,087 个 USDC 最小单位。两笔 Curve 格式转换和后续两池按实际收转串起，收回 596,674，归还 596,087。持有人把差额 587 转给顶层执行合约，第五池实付 354,300,294,823 WETH wei。执行合约解包并把全部 ETH 交给发送人。L2 执行费 626,306,018,772 wei，L1 数据费 262,631,702,415 wei，固定该块哈希的 operator fee 调用返回 0。**发送人的交易前后 ETH 余额实际减少 534,637,426,364 wei**，与回款减两项收费精确相等。前后余额来自同一公共端点的独立 trace 模式，原始收据和有序调用提供不同的核算路径。[实际交易](https://optimistic.etherscan.io/tx/0x82e4dcc08ee474df6d964efdff645d6184c34fd63e05b965f8722ddd48acb7be) · [OP 费用口径](https://docs.optimism.io/op-stack/transactions/fees)

另一笔 OP 交易在执行地址形成可用转账连接的八个市场腿。第一池先给 WETH、最后收 OP，按资金依赖排列的八个日志为 281→259→262→265→268→271→274→279。起点和终点用的是 OP 代币，差额为 **16,757,524,952,701,740 个 OP 最小单位**。其中四腿又形成 WETH 子环；二者共享市场，不可叠加毛差。独立块头确认了位置，整块收据接口被拒；缺该笔统一币种费用归因及最终受益人，账面 OP 增量不能按 ETH 面值计收益。[八市场交易](https://optimistic.etherscan.io/tx/0xcce485a92eb75f60c7f20f0303f1a1b14d3a5327aaac8f4e7d4510fe0c45dae6)

**Arbitrum，先出 USDC、后收 WETH。** 首池向执行地址给出 14,414,778 个 USDC 最小单位，通过两个不同 PoolId 的 v4 市场及另一集中流动性池得到 8,614,399,197,899,068 WETH wei，再给首池 8,605,252,785,462,089 WETH wei 完成结算。按资金顺序为日志 44→33→36→41。末端执行地址只增 9,146,412,436,979 WETH wei。发送人收据网络费为 8,752,989,185,052 ETH wei，其中已含父链费用。若执行地址和发送人同属一方、WETH 按 ETH 面值计，扣网络费后仅余 **393,423,251,927 wei**。已核对 v4 官方 manager、两个不同池标识、双边金额、实际转账和完整块收据根；原生额外付款和地址控制关系仍未知。[实际交易](https://arbiscan.io/tx/0x5d2399ce006d6b5bc333110caf69557931431fcef7d87ff95f934d37c6b945d4) · [Arbitrum v4 部署表](https://developers.uniswap.org/docs/protocols/v4/deployments)

**Era，两笔三池的融资费与 gas。** 一笔交易借入 20,097,332 个 USDC.e 最小单位，三个 Maverick V1 格式的市场腿分别实付实收，最后收回 20,227,317。执行地址偿还本金加 10,048 贷款费，余 **119,937 个 USDC.e 最小单位**。手续费另由发送人实付 35,170,472,000,000 ETH wei，两个币种缺同状态、同数量的实际变现，统一净额留空。另一笔三池闭环以 WETH 出资，执行地址净增 20,551,962,656,255 WETH wei；发送人预缴减退款后实际支付 19,142,243,250,000 ETH wei。同一主体且按面值计的余额余 **1,409,719,406,255 wei**。三池均分别核对实际对手、整数与支付日志；Era 区块按其滚动交易哈希重算，收据按两家服务及原生费用转账交叉核对。[借款三池交易](https://explorer.zksync.io/tx/0x17ce58df5dd676fdf0563891e70af46434e684d6a6fc3dde5cc4da4e6d6f81ec) · [WETH 三池交易](https://explorer.zksync.io/tx/0xa40b340680210b16ab4ed745cf17173e05c413e92acbaaae0b07e92a29df9588) · [Era 哈希规则](https://docs.zksync.io/zksync-protocol/era-vm/transactions/blocks)
