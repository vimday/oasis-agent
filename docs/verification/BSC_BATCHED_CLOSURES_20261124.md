# BSC 60 与 80 Swap 批次的资金闭环、付款与净额

北京时间 2026-11-24。复核此前留存、同一执行器的两笔 BSC 成功交易。**80 条 Swap 是 20 个四跳资金闭环，60 条是 15 个四跳资金闭环**。共 35 个闭环都以 WBNB 进出，且各有正毛差。两笔分别保留 **+10,459,079,088,425** 和 **+9,245,623,944,707 BNB 等值 wei**，已扣实际 gas 及调用树中的直接付款。两笔按既有高事件样本选取，不能用于推算全网套利概率。[先前部分对账](MULTIHOP_EXECUTABLE_EDGE_20261123.md) · [原样本资金边](MULTIHOP_PRETRADE_REPLAY_20261123.md)

每条资金边在前腿出账与后腿入账中对应同一条 ERC-20 转账，逐条核对 token、地址与整数金额。每个闭环只经过四个不同的池，两笔的所有闭环均反复使用同样两个共享池 `0xf2688f…0612c4` 和 `0x225360…8e5e6`，其余池在各笔内部各用一次。两笔均由同一执行器 `0x9af0fb60af553be5aeb7a81372f30a462b24b04d` 向每组首池支付 WBNB，并接收各组最后一腿返还的 WBNB。累计各组本金分别为 `194556164962876843` 和 `131991789089767793` WBNB wei。回调先后与实际资金链有差异，这两个和是逐组成交规模，无法用于推断交易前所需余额。

80 条样本的第一组由 Swap 日志 `4→5→8→9` 与三条资金日志 `2、1、6` 证明。WBNB 从 `109882584073286543` 变成 `109908921799664626` wei，毛差 `26337726378083` wei。最外层的末腿 V3 池先把 WBNB 输出给执行器，执行器再在嵌套回调内将 WBNB 输入支付给资金路线首池。以日志下标直接排序，或把调用栈深度当跳数，都会把资金顺序读错。其余各组与 60 条样本全部逐腿证据保存在复跑结果中。[PancakeSwap V3 调用及事件](https://github.com/pancakeswap/pancake-v3-contracts/blob/main/projects/v3-core/contracts/PancakeV3Pool.sol)

完整块收据内，两笔目标之前，42 池及 32 池集合均未出现其他已识别 V2 / Pancake V3 Swap 事件。目标之后，同池匹配分别出现于 1 笔与 3 笔交易。这个检查只覆盖同块匹配事件，未取得私有提交队列、发生价差的确切时点、其他协议状态变化或可得排序。

## 谁收款，谁付费

每个批次的 WBNB 毛差逐组相加，精确等于执行器的 WBNB 转账净增。两个顶层发件人各自支付实际 gas，未获得本笔 WBNB 转账。执行器还在所有交换完成后分别通过子调用 `[38]` 和 `[28]`，向同一个 `0x4848489f0b2bedd788c696e2d79b6b69d7484848` 支付原生 BNB。它与两个块头费用收款地址均不同。BscScan 公开标注该地址为 **Puissant: Payment**，两笔链上转账本身无法证明哪条渠道提交或谁最终控制资金。付款人与执行器合并是本次交易成本归因范围。两笔均没有 WBNB 包装、解包及其他 ERC-20 转账净额。[独立浏览器标签](https://bscscan.com/tx/0xd049159cc7d6bf024470fd3d70ff2ba7634060b4673670e147a0d9fbdfd5078d) · [48Club Puissant 服务说明](https://docs.48.club/puissant-builder)

两项费用合计分别消耗 **95.46%** 和 **94.90%** 的 WBNB 毛差。全笔发生的 gas 和直接付款可见，单独拆成 20 或 15 笔的反事实成本仍未知。链下返还、基础设施及资金机会成本未纳入。

按实际分组，80/60 条样本的前三大闭环合计分别贡献 **22.87% / 23.80%** 毛差。若将每组毛差单独与 0.05 gwei 比较，并暂设独立付款及其他边际成本为零，两笔中位闭环各最多承担 **213,028 / 242,432 gas**。最薄闭环的同条件上限为 **182,646 / 209,230 gas**。批次优化要测追加一条路径带来的真实边际 gas、共享池滑移和直接付款变化。分组上限由留存 `routes[].gross_profit` 及原交易 gas 价推导，无法从平均每跳 gas 推出。

固定已实现的毛差和直接付款，按观测 gas 价维持严格正净额的 gas 用量上限分别是 **3,956,194** 与 **3,031,667**，比实际多 **209,181** 与 **184,912**。若固定实际 gas 用量，仍盈利的整数 gas 单价上限分别是 **52,791,311** 与 **53,247,776 wei/gas**。这些是已成交结果的单变量敏感性，未来毛差和费用可能同时变化。

后续影子对照应从同一固定状态分别回放已见顺序和备选顺序。每段成交后，更新两座共享池的储备或价格、活跃流动性和初始化 tick，再计算下一段的整数到账。用整笔 gas 和单列的直接付款比较批次与逐笔基线，对照下一可见块是否还覆盖净额门槛。[共享池顺序研究](BSC_V2_BATCH_COMPARISON_20261123.md)
