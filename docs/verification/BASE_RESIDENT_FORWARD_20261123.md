直接子块的组合状态比其父块晚 **919–1,179 ms** 可用。四个新头可用时的名义块龄

## 固定金额的技术与费用对照

在第一组父、子两个固定哈希，分别将 0.001 WETH 经无 hook Uniswap V4 换 USDC，
再经 Uniswap V3 QuoterV2 报价换回 WETH。父、子各两腿均完成，两个终点整数与各自本地模型一致，
最终均为 **994,487,628,414,591 WETH wei**。毛差为 **−5,512,371,585,409 WETH wei**。
扣 500,000 gas ×（5,000,000 base fee + 2,000,000 tip）及 1,951,456,792 wei
的 L1 固定数据探针后，模型净额均为 **−9,014,323,042,201 WETH wei**。
八块的固定 operator scalar 和 constant 均为零。真实整笔 gas、实际 calldata 的 L1 费、
资金、排序及失败成本留空。

两笔逐腿报价耗时 463 和 520 ms，均在已经收到子块状态之后发起。它们复现了同金额
的父子状态技术阴性，未测交易送达或整笔执行。该窗口支持扩大观察覆盖，未提供迁移
交易资金所需的机会和执行证据。
