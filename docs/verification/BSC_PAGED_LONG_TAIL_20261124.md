# BSC 分页留出样本与 89 次成交的批次分解

北京时间 2026-11-24。对固定八地址的 **384 个区块**做分页筛查，得到 **4,000 条匹配、
2,900 笔交易**。独立核对两笔排序首选，完整交易分别有 **52 次与 63 次交换**，
最长可证资金链分别是 **5 跳和 2 跳**。另复核一笔留存的 66 Swap 历史候选，补上
23 条稳定币 `TokenExchange`，合计 **89 次交换**，逐腿证明为 **23 条三至四跳的资金链**。
该历史批次扣实际 gas 和直接付款后，外层付款人与执行器合计增加
**12,777,337,568,834 BNB 等值 wei**。三个完整案例均未证明 20 跳串行。
