## 需要修正的审查细节

1. **提交数**：区间内有 12 个 commit，不是 11 个；140 个文件的数量正确。
2. **P1 引用行号**：原报告指向的 `OasisIntentVault.sol#L291-L299` 实际是 `unpause` 与
   `setGuardian`。接口位于 `L21-L29`，执行路径位于 `L638-L668`。
3. **`atomic_authority.py` 不需要随 ABI 修改**：它只校验 step 元组中的 `pool` 是否在白名单，
   不编码适配器 calldata。需要同步的是合约接口、Foundry mock 和对应测试。
4. **`--readiness-report` 的表述**：运行手册本来没有给出完整的 `run_profit_strategy --mode live`
   命令，因此这是文档缺失，不是“照现有命令执行会立即失败”。部署部分的
   `RolesNotSeparated()` 回滚则是实际存在的风险。
