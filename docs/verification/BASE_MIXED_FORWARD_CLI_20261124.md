V4 读到五个 bitmap 字并将活跃区间传给 Rust。真实 PoolManager 走过空 bitmap 字边界时也会

合并近似为输入 3、输出 1。实际跨字报价与批次晋级应使用完整逐步模型或整笔仿真。
