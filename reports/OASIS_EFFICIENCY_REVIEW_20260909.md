# Oasis Agent 效率优化：第一轮

本轮聚焦实际运行路径：RPC 诊断、候选调度、持久化日志、监控 API 与 WebSocket。没有扩大资金预算、改动 FDV 条件、降低持久化等级或签名/广播交易。

## 错误与日志清理

`RPC rejected eth_call (details redacted)` 是旧客户端丢弃节点原因后的笼统输出，不是具体根因。检查时最新记录仍是这一格式，说明旧格式仍由运行进程产生。首个 fee=500 池的固定区块双源重放确认是 `execution_reverted code=3 revert=SPL`；具体池价边界证据见 BASE_LAUNCH_REFRESH_AND_RPC_ROOT_CAUSE_20260909.md。不能将这一根因套用到全部池。

默认监控视图隐藏旧版无详细原因的记录，并展示隐藏数量及最近旧版错误时间；“显示旧版错误”可恢复查看。完整 append-only 执行日志不删除：它承载仓位、已消耗买入分档、未知提交、预算与重启恢复。隐藏不代表错误已解决。对于最新记录是旧版失败的池，不会用更早的成功报价伪装成当前状态。

## 已实现与测量

| 路径 | 原问题 | 实现及证据 |
|---|---|---|
| Launch 页面 | 每次五个请求重复验证全链，表格跨不同日志快照 | 单一 `/api/v1/launch/dashboard` 共享一次完整核验，旧接口保留；同份快照本地中位耗时 795.04 → 155.84 ms，约 5.1 倍；JSON 394555 → 86831 bytes，约减少 78%（包含默认过滤和报价返回上限） |
| 追加日志 | 每条追加重读全部历史，总成本随历史增长 | `BEGIN IMMEDIATE` 内使用本连接 SQLite data_version + total_changes 判断已验证 head 是否可复用；任何外部提交或额外本连接修改触发完整核验；read/restart 仍完整核验；保持 synchronous=FULL |
| 写入基准 | 5000 条合成历史的全链复核逐条追加 | 20 次测量中位 29.73 → 0.47 ms，约 63 倍；不是主网交易延迟 |
| WebSocket | 首次连接或断线重连发送全部历史，SQLite 核验阻塞事件循环 | 核验放到工作线程；每个事件包最多 50 条，并明确 total_new_records、history_truncated、last_seq；完整历史仍从 API 获取 |
| 扫描 | 大量候选串行，历史实测失败记录跨度达 456/521 秒 | 上轮已实现 8 池批次、流动性事件优先、FIFO 防饥饿、发现后重取区块快照；本轮保留此实现，尚无新代码实盘延迟证明 |
| 页面时效 | 旧时间、无可见刷新状态 | 3 秒轮询、事件刷新、每秒页面时钟、读取超时/陈旧提示、按时间倒序 |

性能证据：evidence/oasis-efficiency-benchmark-20260909.json。页面测试在只读 SQLite 快照上运行；写入基准仅操作临时合成数据库。未写入实盘执行日志。基准只覆盖本机样本，不能外推为全系统或成交速度的同等提升。

## 正确性边界

已覆盖：同连接/外部连接篡改、交替写入者、策略改变、SQL 触发器额外历史写入回滚、完整 read 复核、单请求只核验一次、隐藏旧失败不回退展示旧成功状态、完整审计记录可取回、WebSocket 历史截断可见、重启后的同号扫描轮次不混合。
SQLite data_version 的比较仅在同一连接内进行，且保留写事务内读到的版本；提交之后不读取版本并将其错误绑定到旧 head，避免遗漏其他写入者紧随其后的提交。
依据：https://www.sqlite.org/pragma.html#pragma_data_version 。该优化依赖 SQLite 正常事务/锁语义，不声称防御绕过 SQLite 锁直接破坏数据库文件的操作系统级攻击。

## 下一阶段的效率验收

1. 将端到端发现→报价→模拟→提交→回执的阶段耗时写入监控，并按 venue/provider 区分 p50/p95、超时与限流。当前仍缺实盘新代码端到端样本。
2. 对 RPC 批量读取、连接复用及背压分别做受控基准；不通过无限并发加重公共 RPC 的 429 限流。
3. 对已验证状态/身份进行以区块哈希和代码版本为键的缓存设计；在证明失效策略前不缓存资本决策输入。
4. 为长期存储设计可验证的归档检查点与恢复迁移，验证预算/仓位恢复等价后再缩减活跃数据库；不能直接截断现有 hash chain。

上线边界：只读 UI 已启用合并快照和旧错误隐藏。执行侧的新日志追加优化与扫描调度需现有交易进程重新加载才会生效；本轮没有重启交易进程，不声称实盘已提速。没有修改合约。
